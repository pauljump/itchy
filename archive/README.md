# Where Usual started

The active product is [Usual](../README.md). These files preserve the experiments
that led here; none are needed by the installer or current runtime.

- [Itchy](itchy/README.md): original byte-level language model, notebooks, competition records, and training scripts. Read its [results correction](itchy/CORRECTION.md) alongside the historical scores.
- [Preference learning](preference-learning/README.md): intermediate local classifier and shadow-only personal-choice experiments. They were not validated as a production personal model.
- [Whetstone handoff](whetstone-handoff.md): development notes from Usual's working name. Paths and status are historical.

The original Itchy Git history remains in this repository. Usual's active source was
imported from `pauljump/whetstone`, local commit `c28ff14`, then renamed and consolidated
here. [The evolution](../references/evolution.md) explains the connection.
